# Usability & accessibility checklist (NFR-05, TC-057)

Check every page in **both themes** (toggle bottom-right). Mark ✔ / ✘ and note the page.

| # | Check | How to check |
|---|---|---|
| 1 | Theme choice is remembered after reload | Switch to dark, press F5 – page stays dark |
| 2 | No white flash when loading in dark theme | Dark theme, hard reload (Ctrl+Shift+R) |
| 3 | Every amount uses Indian grouping (₹1,65,000.00) | Dashboard, Assets, Loans, Ledger, Import, Projection, Reports |
| 4 | No chart uses colour alone | Each chart has a legend, labels or a table with the same numbers |
| 5 | Every input has a visible label or `aria-label` | Tab through each form |
| 6 | Errors are shown as text next to the form | Submit an empty / invalid form |
| 7 | Text is readable in both themes | No grey-on-grey; links and buttons visible |
| 8 | Pages work at 360 px width | Browser dev tools → mobile size |
